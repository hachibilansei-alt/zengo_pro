Zengo Pro v20 — مجله فیلم، سریال و بازی + حساب کاربری و نظرات
============================================================

اجرا:
1) Python 3.10+
2) pip install -r requirements.txt
3) run_windows.bat
4) http://127.0.0.1:5000

حساب کاربری (بالای سایت):
- ثبت‌نام / ورود فقط با نام کاربری و رمز عبور (بدون ایمیل)
- پس از ورود می‌توانید زیر هر مطلب نظر بگذارید

ادمین محتوا:
- /admin/login  کاربر: admin
- رمز پیش‌فرض را قبل از انتشار عمومی عوض کنید

محتوا:
- ۵۰ نقد بازی + ۵۰ نقد فیلم/سریال + مطالب تحریریه
- پوسترها در static/uploads
- دیتابیس naqd_nama.db همراه بسته است

قابلیت‌ها:
- تم تاریک/روشن، حلقه امتیاز، نوار پیشرفت مطالعه
- جست‌وجو، فیلتر ژانر/پلتفرم، مطالب مرتبط
- سیستم نظرات کاربران
- sitemap و robots

امنیت انتشار:
- SECRET_KEY را در متغیر محیطی تنظیم کنید
- رمز ادمین را قوی کنید
